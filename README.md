# PixelCat（像素猫）

一个轻松向的 2D 像素动作小游戏，用 **Godot 4.7** 制作。白天在家照顾小猫、做点手工，夜晚带着小猫出门，在树林里打史莱姆、找小秘密。

> 美术目前大部分是占位的（程序生成的地砖、界面），会由美术同学逐步换成手绘。逻辑和美术是分开的，换图不需要改代码。

## 游戏玩法

### 白天：在家

- 屏幕左上角有三条状态：**饥饿、心情、精力**，会随时间慢慢下降。
- 家里有可以互动的东西（靠近后按 **E**）：
  - 饭碗：饥饿 +20
  - 玩具：心情 +20
  - 小床：精力 +20
  - 小桌子（工作台）：打开合成
  - 小门：出门，进入夜晚
- **出门前的状态会影响夜晚**：饥饿低于 30，攻击 ×0.9；心情高于 70，移动速度 ×1.1；精力高于 70，最大生命 +1。
- 按 **I** 打开背包，里面可以打开**合成**界面；按 **1～4** 使用绑定到快捷栏的物品。

### 合成

- **随身合成**：在背包里随时可以做基础配方（例如 2 个毛线 → 1 个毛线球）。
- **工作台合成**：在家里的工作台前可以做高级配方（例如毛线逗猫棒，使用后心情 +20）。
- 可以**一次做多个**（− / ＋ / 最大），配方按“可制作 → 材料不足 → 需要工作台”排序。

### 夜晚：探险

- 通过小门出门。一开始只能去**公园**；**第一次通关公园之后**，出门会弹出选图界面，可以去**小树林**。
- 每张图的目标：**打败所有算目标的史莱姆**，然后走进**出口**回家。右上角显示进度；剩下几只时，屏幕边缘会出现小箭头指向它们，全部打完后箭头指向出口。
- 打败史莱姆会掉小鱼干和材料（毛线、木材、石头）。
- 地图里藏着**“猫猫的小秘密”**：小树林的老树洞会教会你一个新招式，不是通关必需。
- **成功撤离**会弹出结算画面：击败敌人、小鱼干、经验、本次带回的物品、新学会的招式、首次通关和解锁的新地图。
- **倒下就结束这次探险**，没有复活：小鱼干丢一半；**背包里随机丢一半可丢失的物品**，合成出来的成品等“受保护的物品”不会丢；经验和已学会的招式都保留。

### 战斗

| 操作 | 效果 |
| --- | --- |
| **J** 爪击 | 连按两下是二连击。学会后可以 J J J 三连击。 |
| **K** 黏黏球 | 发射毛线球，命中会缠住敌人一小会儿，冷却较长。 |
| **Z** 防御 | 按住举盾。敌人扑过来的最后一瞬按下是**完美防御**。 |
| **Shift** 闪避 | 短暂无敌，冷却长。在敌人攻击命中前的最后一瞬闪开是**完美闪避**，冷却立刻清零并打开反击机会。 |
| **空格** 冲刺 | 快速位移，有 2 次充能，**没有无敌**，可以打断挥爪。 |

- **招式**（靠探索学会）：**三段连击**（J J J）、**扑击**（冲刺后按 J）、**反击爪**（完美闪避后按 J）。扑击和反击爪必定击晕敌人。
- **绕背暴击**：攻击面朝别处的敌人的背后，有 50% 概率暴击，伤害 ×2。
- **接触史莱姆**：碰到活着的史莱姆有一定概率（不是每次）让你滑倒（失控约 0.6 秒）或被黏住（变慢、不能冲刺和闪避约 1.2 秒），触发后 2 秒内不会再中招。
- 命中会有火花、伤害数字、顿帧和轻微震屏，每一类效果都有开关。

### 成长

- 打败敌人获得经验，升级得到**属性点**，按 **P** 打开成长面板分配：生命、攻击、防御、敏捷。
- 成长面板下方的“招式”区显示已学会的招式。更多技能以后会加入。

### 存档

- 自动存档。主菜单的“继续游戏”会回到上次的位置：白天回到家，夜晚探险中途退出会回到那张地图继续。

## 怎么运行

1. 安装 **Godot 4.7**（标准版，不是 .NET 版）。
2. 用 Godot 打开项目文件夹里的 `project.godot`，第一次会花一两分钟导入资源。
3. 按 **F5** 运行完整游戏，或者：
   - 打开 `scenes/dev/play_forest.tscn` 按 **F6**，直接站在小树林里（不写存档，不用先通关公园）；
   - `play_forest_all_moves.tscn`：带着全部招式进小树林；
   - `play_park.tscn`：直接进公园。

更详细的试玩说明和“试玩时请重点看什么”见 [docs/how-to-play.md](docs/how-to-play.md)。

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `scenes/` | 场景：`main.tscn`（白天的家）、`worlds/`（夜晚地图）、`ui/`、`enemies/`、`player/`、`menu/`、`dev/`（试玩入口） |
| `scripts/` | 游戏逻辑。`cat_controller.gd`（小猫移动/冲刺/闪避）、`player_combat.gd`（近战和招式）、`enemies/slime.gd`（史莱姆）、`progression_manager.gd`（成长和存档）、`expedition_manager.gd`（探险）、`hit_feel.gd`（打击反馈） |
| `resources/` | 物品、配方、主题（`ui/pixelcat_theme.tres`）、战斗调参（`config/`） |
| `assets/` | 美术、音频、字体、地砖 |
| `tests/` | 自动测试，见下 |
| `tools/` | 开发工具：生成占位美术、地图数据、界面主题（每个脚本开头有用法说明） |
| `docs/` | 设计和说明文档 |

## 测试

```
GODOT=/path/to/godot bash tests/run_all.sh          # 全部（约 5 分钟）
GODOT=/path/to/godot bash tests/run_all.sh slime    # 只跑名字里含 slime 的
```

每个测试用独立的临时存档目录，并开启测试模式（战斗里的随机效果默认关闭，保证结果稳定），不会改动你的真实存档。

## 调手感

战斗的数值（冲刺距离、暴击概率、滑倒概率、招式伤害……）都集中在 `scripts/combat_v3_tuning.gd`，用 Godot 的检查器就能调。打击反馈的强度在 `scripts/hit_feel.gd`。
