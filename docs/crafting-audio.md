# 合成界面音效接入說明（給負責音樂的同學）

合成界面已經為每個動作留好了「音效槽」，**不需要改任何代碼**：把音效文件拖進槽里就會在對應時機播放。槽是空的就靜音。

## 步驟

1. 把音效文件放進 `assets/audio/sfx/crafting/`（wav / ogg / mp3 都行；短音效推薦 wav 或 ogg）。
2. 在 Godot 里打開 `scenes/ui/crafting_ui.tscn`，點選根節點 **CraftingUI**。
3. 在右側「檢查器」找到 **Audio (assign in Inspector)** 分組，把文件拖到對應的槽。
4. 試聽：在 Godot 里打開 `scenes/dev/crafting_audio_preview.tscn`，按 **F6**（運行當前場景）。它一打開就是合成界面、材料已備好，**不會寫入存檔**。
   - **R**：補充材料　**Tab**：切換「隨身／工作台」模式
5. 需要整體調音量時改 **Sound Volume Db**（0 為原音量，−6 約減半）。

## 有哪些槽、什麼時候響

| 槽 | 觸發時機 | 建議風格 |
| --- | --- | --- |
| Sound Open | 打開合成界面（背包里點「制作物品」或在工作台按 E） | 輕柔的「叮」或翻開的聲音 |
| Sound Close | 關閉合成界面 | 比打開略低、略短 |
| Sound Select Recipe | 在左邊點選另一個配方 | 很輕的點擊，會常常聽到，別太搶 |
| Sound Quantity Change | 點 −／＋／最大 改數量 | 小而輕的滴答，會連續觸發 |
| Sound Craft Success | 制作成功（圖標彈一下、浮出 +N 物品） | 最重要的一個：開心、有成就感，約 0.5～1 秒 |
| Sound Craft Fail | 嘗試制作但失敗（材料不夠、背包滿） | 輕輕的「嗯嗯」，不要刺耳 |

## 小提示

- 「選擇配方」和「數量變化」可能被連續快速觸發，所以請做得短（<0.2 秒）且音量小。
- 一次做多個（比如 ×5）只播放**一次**成功音效。
- 目前所有音效走 Master 總線；如果之後想單獨調 UI 音量，可以在 Godot 的音頻總線里新建 `SFX` 總線，再告訴我改 `bus`。
- 試聽場景只用來聽音效；正式遊戲里的觸發時機和它完全一樣。
