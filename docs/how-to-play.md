# 怎么试玩（给第一次试这个版本的人）

目标：十分钟内跑起来，直接站在“小树林”里打。

## 第 1 步：准备 Godot 4.7

1. 打开 https://godotengine.org/download ，下载 **Godot 4.7**（**标准版**，不要选 .NET / C# 版）。
2. 下载的是压缩包，**解压就能用，不需要安装**。双击里面的 Godot 程序即可。

## 第 2 步：拿到最新的项目

**方法 A（最省事，不需要 git）**：下载项目压缩包，解压到任意文件夹：

https://github.com/Kysuke727/pixelcat/archive/refs/heads/main.zip

（需要登录 GitHub。如果你已经有 pixelcat 文件夹并用 GitHub Desktop，也可以：Fetch origin，然后确认左上角 Current Branch 是 `main`，Pull 一下就是最新的。）

## 第 3 步：用 Godot 打开

1. 打开 Godot，在项目管理器点 **导入（Import）**，选解压出来的文件夹里的 `project.godot`，再点“导入并编辑”。
2. **第一次打开会花一两分钟导入资源**，右下角有进度，等它跑完。看到一些黄色警告是正常的。

## 第 4 步：一键进小树林（推荐）

1. 在左下角“文件系统”里打开 `scenes/dev/` 文件夹。
2. 双击 **`play_forest.tscn`**（想一上来就带着全部招式试连招，选 `play_forest_all_moves.tscn`）。
3. 按键盘 **F6**（运行当前场景）。

你会直接站在小树林的起点。这个试玩入口：
- **不会写入你的存档**，随便玩；
- 不需要先通关公园；
- 走到出口或者生命用完，会回到家里，和正式游戏一样。

想试公园，用 `play_park.tscn`。要玩完整的正式流程，直接在项目里按 **F5**。

## 按键

| 按键 | 作用 |
| --- | --- |
| W A S D | 移动 |
| J | 爪击（连按两下是二连击） |
| K | 黏黏球（毛线球，命中会缠住敌人，冷却较长） |
| Z | 防御（按住）。敌人扑过来的最后一瞬按下是**完美防御** |
| Shift | 闪避（无敌 0.15 秒，冷却 15 秒） |
| 空格 | **猫步冲刺**（2 次充能，没有无敌） |
| E | 互动（在家里开门、用工作台） |
| I | 背包（里面可以打开合成） |
| F3 | 调试面板（隔离模式，里面也有“解锁全部招式”） |
| P | 成长面板：属性加点，查看已学会的招式 |

### 新的战斗技巧

- **碰到史莱姆**不一定会怎样：有 35% 的概率让你**滑倒**（失控约 0.6 秒）或**被黏住**（变慢、不能冲刺闪避约 1.2 秒），触发后 2 秒内不会再中招。
- **绕背暴击**：攻击面朝别处的史莱姆的背后，有 50% 概率**暴击（伤害 ×2）**。史莱姆扑空之后趁它硬直绕到后面打。

- **完美闪避**：敌人的攻击快打到你的那一瞬间按 Shift，闪避冷却会**立刻清零**，还会有一小段慢动作。
- **扑击**（需要先学会）：按空格冲刺之后立刻按 J。
- **反击爪**（需要先学会）：完美闪避之后 1 秒内按 J。
- **三段连击**（需要先学会）：J J J。
- 左上角的小面板里有血条、护盾条、`冲刺 ●● · 闪避 就绪`（实心圆点是还剩几次冲刺）和黏黏球状态。底部中间的提示条只在开局前 15 秒显示按键提示，之后只有发生事情（命中、滑倒、完美防御…）才会出现。

## 小树林怎么玩

- 目标：**打败外面的 8 只史莱姆**（右上角显示“目标 x/8”），然后走进右边的**出口**。
- 剩 3 只以内时，屏幕边缘会出现红色小箭头指着它们，数字是大概的距离；全部打完后，箭头变成金色，指向出口。
- **倒下就结束这次探险**：会弹出结算画面（击败多少敌人、小鱼干保住多少、**背包随机丢一半物品**，受保护的物品不丢），点“回家”回到家里。不会复活，也没有安全点。
- **成功走进出口**同样会弹出结算画面：击败敌人、小鱼干、经验、**本次带回的物品**，以及新学会的招式、首次通关和解锁的新地图，点“回家”回到家里。
- **有一个秘密**：入口那块空地的北边，有一条被灌木半挡住的窄小径，地上有很淡的爪印。顺着走到尽头的老树洞，会学会**三段连击**。小径里的史莱姆不算通关目标，打不打都行。

## 试玩时请重点看（有感觉就告诉我）

1. **冲刺**的距离和节奏顺不顺？2 次充能够不够？
2. **完美闪避**的慢动作是不是太长或太短？
3. 打中敌人的**顿帧和震屏**会不会太强？（强度都在 `scripts/hit_feel.gd` 里，很好调）
4. **三段连击、扑击**的手感和伤害。
5. **小树林**：路好不好走？敌人多不多？中央空地同时打 4 只会不会太难？有没有被树卡住的地方？
6. 左上角的战斗面板（现在是紧凑的小面板）看得清吗？提示条会不会遮挡？
7. **死亡结算**：丢一半背包物品的规则合不合适？结算画面看得清吗？
8. **滑倒/黏住**的概率和时长会不会太烦？**绕背暴击**好不好触发？

## 遇到问题

- 打开项目报版本不对：确认用的是 Godot **4.7**，而且是标准版。
- 第一次运行很慢：是在导入资源，等一会儿就好。
- 按 F6 没反应：先点一下中间的场景编辑区域，再按 F6；或者用右上角的“运行当前场景”按钮（电影胶片图标）。
