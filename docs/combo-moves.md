# 招式系统与连招（阶段 2）

对应设计文档 `docs/combat-exploration-design.md` 的第 2 阶段。建立在阶段 1（`docs/combat-foundation.md`）之上。

## 三个可学的招式

| 招式 | 输入 | 效果 |
| --- | --- | --- |
| 三段连击 | J J J | 第二下命中后的窗口内再按 J，打出第三下：伤害 3、范围更大（1.5 倍）、击退更强，**必定眩晕**敌人。 |
| 扑击 | 冲刺后立刻 J（冲刺开始后约 0.4 秒内） | 向前扑出约 80 像素的重击：伤害 3、范围 1.4 倍、**必定眩晕**。落地后有 0.75 秒硬直，**扑击途中没有无敌**，被打到会中断。 |
| 反击爪 | 完美闪避后 1 秒内按 J | 快速反击：伤害 2、范围 1.25 倍、**必定眩晕**。会用掉这 1 秒的反击机会。 |

细节：

- 同时满足反击和扑击的条件时，优先反击爪。
- 招式只能在空闲或收招时开始，不能打断另一个攻击动作（冲刺例外，冲刺可以接扑击，也可以打断普通挥爪）。
- 没学会的招式完全不影响原来的手感：未学三段连击时，第二下仍是连招的最后一下。
- 屏幕左上的战斗界面会显示已学招式的提示（“J×3 三段”）和当前可用的机会（“扑击！按 J”“反击机会！按 J”）。

## 连招奖励

三段连击的第三下、扑击、反击爪命中时，**随机**给一个小奖励（五五开）：

- 1 个小鱼干（夜晚探索中算作本次探索的小鱼干）
- 心情 +3（加到回家后的心情上，不超过 100）

同一次挥爪即使打中多个敌人，也只给一次奖励。奖励数值在 `CombatV3Tuning` 的“连招奖励”分组里调整。

## 怎么学会招式

招式通过**探索地图**获得（设计见设计文档第 5 节），这部分要等阶段 3（大地图加“猫猫的小秘密”地点）。在那之前，试玩用调试面板：

1. 在夜晚地图按 **F3** 打开调试面板。
2. 点“解锁全部招式”（或“清空已学招式”）。
3. 调试面板是隔离模式，关闭后会还原，**不会写入存档**。

学会新招式时，屏幕顶部会弹出提示条：招式名称、按键和说明。

给程序用的接口（阶段 3 的“小秘密”地点会调用它）：

```gdscript
ProgressionManager.unlock_move("pounce")   # 学会一个招式；已学会则返回 false
ProgressionManager.has_move("pounce")
```

招式的名称、按键和说明集中在 `scripts/move_catalog.gd`（简体中文），新增招式时在这里加一条。

## 存档

存档里新增 `unlocked_moves` 列表。旧存档没有这个字段，读取时视为“一个都没学”，不会报错；存档里出现这个版本不认识的招式 ID 时会被忽略。

## 怎么调手感

`scripts/combat_v3_tuning.gd` 的“连招招式”分组：

- 三段连击：`third_claw_damage`（3）、`third_claw_knockback_multiplier`（1.5）、`third_claw_hitbox_scale`（1.5）
- 扑击：`pounce_damage`（3）、`pounce_distance`（80）、`pounce_move_duration`（0.18）、`pounce_duration`（0.32）、`pounce_recovery`（0.75）、`pounce_window_after_dash`（0.3）、`pounce_hitbox_scale`（1.4）
- 反击爪：`counter_claw_damage`（2）、`counter_claw_hitbox_scale`（1.25）

## 测试

- `tests/combo_framework.gd`（77 项）：解锁、存档读写与兼容、三段连击、扑击（含 30/60/144/240 Hz 下距离都是 80 像素）、反击爪、优先级、奖励的随机与只给一次、HUD、调试面板。
- `tests/combo_real_input.gd`（12 项）：用**真实按键事件和真实时间**走完整条链路——连按 J 缓冲进入第二、第三下，空格冲刺后按 J 扑击并命中。
- 没学招式时所有原有近战测试结果不变。
