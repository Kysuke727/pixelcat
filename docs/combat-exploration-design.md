# 战斗与探索改造设计（草案，待确认）

> 状态：**草案**。目的是先把方向和顺序定下来，再动手。标记为“待确认”的地方需要策划（项目主人）拍板。

## 1. 设计原则：轻松向，但有深度

游戏的底色是“轻松向”。“战斗不够爽”不等于要变难，所以定下这几条：

1. **容错高，表达空间大。** 打不好也能过关；操作漂亮则有额外奖励（小鱼干、心情、特效），而不是“不会连招就打不过”。
2. **位移是乐趣，不是无敌。** 多给玩家能灵活移动的手段，但无敌帧仍然稀有，这样位移可以放心给得多。
3. **每个新招式单独拿出来都好玩。** 不做“必须搭配才有用”的技能。
4. **技能来自探索。** 地图里藏着可以学会新招式的地方，找到就是奖励。
5. **不改变现有的伤害和血量基调**（玩家 5 血、怪物每次 1 点伤害），“轻松”的手感要保留。

## 2. 现状（已核实）

| 方面 | 现状 |
| --- | --- |
| 近战 | 2 连击（第一段 1 伤害，第二段 2 伤害），第二段有 50% 几率眩晕敌人 |
| 远程 | 毛线球命中后缠住敌人 1.8 秒，冷却 4 秒 |
| 闪避 | 位移 55 像素，无敌 0.15 秒，**冷却 15 秒**（原先 3～4 秒，因为无敌太强被调长） |
| 防御 | 举盾，耐久 100，有完美格擋（会让敌方短暂暂停） |
| 成长 | 升级加血量、攻击 +5%、防御、敏捷；技能点里的“连接”“绕圈”属于已删除的 V3 玩法，基本没有效果 |
| 敌人 | 只有一种史莱姆：游荡 → 追击 → 蓄力 0.68 秒 → 扑击 → 硬直；夜晚地图固定 3 只 |
| 反馈 | 只有敌人受击白闪和击退；没有顿帧、震屏、火花、伤害数字 |
| 镜头 | **没有 Camera2D**，游戏是固定的单屏 1152×648 |

## 3. 位移系统：把“位移”和“无敌闪避”拆开

**问题**：现在只有一个又远又短的闪避，同时承担了“位移”和“保命”两件事。冷却长则不灵活，冷却短则太强。

**方案**：

- **猫步冲刺（新）**：短距离快速位移（约 90 像素），冷却约 1.2 秒，**没有无敌帧**。它只是让走位更灵活，不能用来“无敌穿怪”，所以可以放心给得频繁。待确认：是否给 2 次充能。
- **闪避（保留）**：仍是无敌闪避，保持长冷却，作为“应急按钮”。
- **完美闪避（新）**：在敌人扑击命中前的最后一瞬闪避，**返还闪避冷却**，并触发一小段慢动作。这是“技巧换回报”：打得好，闪避就能频繁用；打不好，仍然安全，只是用得少。（游戏里已有完美格挡和“敌方暂停”机制，可以复用。）

## 4. 连招：用已有按键组合出新招

现有按键：近战 J、毛线球 K、闪避 Shift、举盾、冲刺（待定键位，建议空格）。

| 招式 | 输入 | 效果 | 解锁方式 |
| --- | --- | --- | --- |
| 三段连击 | J J J | 第三段范围更大、击退更强 | 探索获得 |
| 扑击 | 冲刺后立刻 J | 向前扑出去的重击，伤害高、有硬直 | 探索获得 |
| 反击爪 | 完美闪避后 J | 一次快速反击，必定造成眩晕 | 探索获得 |
| 毛线拉扯 | 毛线球命中后 J | 把被缠住的敌人拉到面前，并接一次攻击 | 探索获得 |

规则：

- 所有连招都带**输入缓冲**（约 0.2 秒），不要求精确按键，保持轻松。
- 打出连招有额外的小奖励（特效、少量心情或小鱼干），**但不是必须**。
- 冲刺和基础连击是初始就有的，让前期就能玩得开心。其余通过探索获得。

## 5. 探索获得技能：“猫猫的小秘密”

- 每个技能对应地图上的一个**特定地点**（比如屋顶、花园角落、旧纸箱）。到达后触发一小段演出，并给一个能马上试用的小场景。
- 地点有微弱的视觉提示（爪印、闪光），不用靠攻略也能发现。
- **不做硬卡关**：技能不是通关的门槛。但有些位置用冲刺更容易到达，作为“软性”探索动机。
- 这一条让“大地图”有了存在的理由：不是为了大而大，而是技能藏在里面。

技术上：存档里新增“已解锁招式”列表（需兼容旧存档），由 ProgressionManager 管理，战斗控制器按解锁状态决定能否使用某个招式。

## 6. 实施顺序

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| 1. 地基 | Camera2D、打击反馈（顿帧、震屏、火花、伤害数字）、猫步冲刺、完美闪避 | 夜晚地图可玩；手感明显更好；测试全过 |
| 2. 连招框架 | 招式解锁系统、存档、三段连击、扑击 | 可在测试场景里试每个招式 |
| 3. 大夜晚地图 | 可滚动的大地图，放 3～4 个“小秘密”地点，各教一招 | 能完整走一遍并学会所有招式 |
| 4. 敌人家族 | 植物史莱姆（远程吐弹，美术已有）、分裂、带盾、冲锋，最后一个小 boss | 每种怪需要不同应对 |
| 5. 装备合成 | 用材料合成爪套、项圈、护符，改变招式效果 | 合成系统与战斗接上 |
| 6. 白天世界扩大 | 白天家园和周边变成可滚动的大地图 | 与夜晚共用镜头系统 |

每个阶段单独成一个分支，测试全过后才合入 main。

## 8. 风险

- **旧存档**：新增解锁数据要兼容旧存档（已有保存格式的版本检查可以复用）。
- **改动面大**：战斗控制器、史莱姆、存档、地图都会动，所以按阶段小步合入，每步跑完整测试。
- **“轻松向”的边界**：每个阶段做完都要在真机上试玩，由你判断是否偏离了“轻松”。
