# 战斗地基（阶段 1）：冲刺、完美闪避、打击反馈、镜头

对应设计文档 `docs/combat-exploration-design.md` 的第 1 阶段。

## 新操作

| 操作 | 按键 | 说明 |
| --- | --- | --- |
| 猫步冲刺 | **空格** | 朝移动方向（没有输入时朝面向方向）冲出约 90 像素。**没有无敌帧**，被打到照样受伤。有 2 次充能，每 1.2 秒恢复 1 次。冲刺可以打断近战挥爪。 |
| 闪避 | Shift | 和以前一样：无敌 0.15 秒，冷却 15 秒。 |
| 完美闪避 | （自动） | 敌人的攻击在**闪避的无敌帧内**命中，就算完美闪避：**闪避冷却立刻清零**，出现慢动作和“闪避！”字样，并打开 1 秒的“反击机会”（供后续连招使用）。普通的受击无敌不算完美闪避。 |

战斗界面（左上）新增一行：`冲刺 ●● · 闪避 就绪/冷却`，实心圆点是可用的冲刺次数。

## 打击反馈

所有效果集中在自动加载脚本 `scripts/hit_feel.gd`（节点名 `HitFeel`），玩法代码只调用几个语义函数：

| 事件 | 效果 |
| --- | --- |
| 近战命中 | 火花、伤害数字、短暂顿帧、轻微震屏（第二段连击更强，数字是金色） |
| 毛线球命中 | 粉色火花、伤害数字、轻微震屏 |
| 敌人死亡 | 绿色爆开、较长顿帧、震屏 |
| 玩家受伤 | 红色火花、顿帧、较强震屏 |
| 完美闪避 | 青色火花、“闪避！”、0.3 秒慢动作 |
| 完美防御 | 金色火花、“完美防御！”、震屏 |
| 冲刺 | 一串逐渐变淡的残影 |

“轻松向”的考虑：每一类效果都有开关，以后可以做成设置菜单里的选项（对晕动敏感的玩家可以关掉震屏和顿帧）：

```
HitFeel.hit_stop_enabled / slow_motion_enabled / screen_shake_enabled
HitFeel.particles_enabled / damage_numbers_enabled
```

测试模式（环境变量 `PIXELCAT_TEST_MODE=1`）下，顿帧和慢动作默认关闭，保证测试结果稳定。

## 镜头

夜晚、白天场景里加入了 `CombatCamera`（`scenes/combat/combat_camera.tscn`）。它固定在世界左上角，**画面和以前完全一样**，目前只用来震屏（震动幅度最大 5 像素，且按整像素偏移，不会让像素画闪烁）。后面做大地图时，它会升级成跟随玩家的镜头。

## 怎么调手感

数值都在 `resources/config/combat_v3_tuning.tres` 对应的脚本 `scripts/combat_v3_tuning.gd` 里（在 Godot 里选中这个资源，右侧检查器里能看到“猫步冲刺”“完美闪避”分组）：

- `dash_distance`（默认 90）、`dash_duration`（0.12）、`dash_max_charges`（2）、`dash_recharge_time`（1.2）
- `perfect_dodge_counter_window`（1.0）

震屏、顿帧的强度和时长写在 `hit_feel.gd` 里各个 `melee_hit`、`enemy_died` 等函数中，数字都很直观，可以直接改。

## 测试

`tests/combat_foundation.gd`（58 项检查）覆盖：冲刺的充能与恢复、无无敌、距离（30/60/144/240 Hz 下都是 90 像素）、被禁止的状态、完美闪避的触发与只触发一次、普通无敌不算、镜头不改变画面、震屏衰减、顿帧会恢复、各类效果的开关、命中时出现伤害数字。

另外 `tests/combat_v3_1_phase_02.gd` 里的闪避测试按新规则做了更新：闪避无敌帧内被命中现在算完美闪避，会返还冷却。

## 已知限制 / 后续

- 还没有设置菜单，上面的效果开关目前只能在代码里改。
- “反击机会”窗口已经能打开（界面上会提示），但反击爪这个招式要到阶段 2 才做。
- 音效：打击、闪避、冲刺目前没有新增音效，等音乐同学来配（和合成界面的音效槽同样的思路）。
