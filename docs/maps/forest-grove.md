# 第 1 张新地图：公园外的小树林

配图：`docs/maps/forest-grove-layout.png`。已经做好，可以玩。

## 一句话

一片很大的夜晚树林：一条从左下角通到右上角的主路，三条岔路各通向一块空地（旧长椅、蘑菇圈、小仓库），一条藏在灌木后面的秘密小径通向西北角的老树洞，路上有营地、倒树、小池塘和路牌。地图大小 4608×2560（144×80 格，每格 32 像素，约 4×4 屏），画面跟着小猫滚动，不会照到地图外面。夜里有路灯、营火、萤火虫和暗角。

## 怎么进来

- **通关公园之前**：夜晚出门和以前一样，直接去公园，不会看到选择界面。
- **第一次通关公园（清空史莱姆、走进出口）之后**：夜晚出门会先弹出“今晚去哪里探险？”，可以选“公园”或“小树林”。已通关的地图会标 ✓。
- 想先不出门，点“先不出门”或按 Esc。
- 探险进行到一半存档、退出再继续，会回到你选的那张地图。

## 通关规则（和公园一样）

- 打败**外面的 19 只**史莱姆，出口才会开启；走进出口算成功撤离，并记录“已通关小树林”。**三个支线地点各有一只守卫（秘密小径、蘑菇圈、小仓库，共 22 只里的 3 只）不算通关目标**，打了照样掉东西、读档后也不会复活，不打也能通关。
- 屏幕右上角显示“目标 x/19”。剩 5 只以内时，屏幕边缘会出现红色小箭头指向它们（只指向算目标的敌人，不指向守卫），全部打完后变成金色箭头指向出口。
- **没有安全点，也没有复活**：倒下就结束这次探险，弹出结算画面，背包随机丢一半物品（见 `docs/death-and-contact.md`）。
- 走进出口成功撤离，同样会弹出结算画面，显示这次的收获。

## 藏宝点

地图里有 4 个藏宝点（小布袋，会发暗金色的光），其中蘑菇圈、营地、旧长椅三个各有 1 个草药包：走进去就能拿，每次探险只能拿一次，读档后也不会重复。**背包放不下的时候一样都不会拿**，会提示“背包放不下了”，清出位置再来就行。

## 路牌

三块路牌指向三条岔路，字在夜里也看得清。

## 猫猫的小秘密

- 入口空地东北边有一条被灌木半挡住的窄小径，入口附近的地上有**很淡的爪印**当提示。小径很长，一直通到地图西北角。
- 走到老树洞，触发“猫猫的小秘密！”，学会三段连击，屏幕顶部弹出提示条。再来一次只会提示“这里你来过了”。
- 不是通关必需。

## 怎么改这张图（给你和美术同学）

这张图是用**地砖地图（TileMapLayer）**做的，美术是占位的，可以直接替换，不需要改任何关卡代码：

1. **换地砖图**：用 Aseprite 画一张 352×32 的图（11 个 32×32 的格子排成一行），顺序是：草地 A、草地 B、土路、树 A、树 B、树 C、灌木、水、花丛、小石头、浅色土路（秘密小径）。覆盖 `assets/tilesets/forest_tiles.png` 就行。碰撞（树、灌木、水不能走）已经设在地砖上。
2. **直接在 Godot 里重新刷地图**：打开 `scenes/worlds/forest_grove.tscn`，选中 `Terrain` 节点，用地砖地图编辑器画。
3. **换道具图**：`assets/props/` 里的 `pawprint`（爪印）、`tree_hollow`（老树洞）、`fallen_log`、`stump`、`campfire`、`bench`、`mushroom`、`signpost`、`loot_sack`，都是小图，直接覆盖即可。
4. 敌人、出口、秘密点、藏宝点、路牌都是场景里的普通节点，在 Godot 里直接拖动位置即可。

## 重新生成（只有想从头来过时才需要）

关卡数据在 `tools/forest_grove_data.py`（唯一的数据来源）。改了数据之后：

```
python3 tools/make_forest_tiles.py      # 生成地砖图、占位美术、地砖网格，并检查设计
python3 tools/draw_map_layout.py        # 重画 docs/maps/forest-grove-layout.png
godot --headless --path . --script res://tools/build_forest_grove.gd   # 重新生成场景
```

`make_forest_tiles.py` 会自动检查：所有敌人、出口、秘密点、藏宝点、路灯、各条岔路和小径的尽头都必须站在可走的地面上，并且从出发点能走到。**注意**：重新生成场景会覆盖你在 Godot 里手动改过的内容。

## 测试

`tests/forest_grove.gd`（100 多项，数据来自关卡 JSON）包括：场景结构、22 只敌人（19 只算目标、3 只守卫）、地砖数据里的可达性、**用真实物理碰撞让小猫沿主路走到出口、沿三条岔路和秘密小径走到尽头**（走不通就失败）、树和池塘能挡住小猫、走到树洞真的学会招式且只学一次、藏宝点（背包满了不会拿、拿一次、不会重复）、路牌、爪印足够淡、镜头跟随并且不会照到地图外面、只杀守卫不会让出口开启、只杀外面 19 只就会开启并记录通关、出发点和关卡数据一致。`tests/loot_stash.gd` 覆盖“全有或全无”的背包添加、藏宝点存档状态和读档兼容。`tests/enemy_compass.gd` 覆盖方向箭头，`tests/map_system.gd` 覆盖选图界面和存档兼容。

## 已知限制 / 后续

- 美术是占位的程序生成图，比较单调（树墙都是同样的方块），等你们换成手绘的。
- 史莱姆会沿地砖网格绕过树、灌木、路灯和路牌（`scripts/nav_grid.gd`）；看不到小猫时不会扑击；绕路太远或 1 秒没有进展就放弃追击。`tests/slime_pathing.gd` 验证。
- 白天的家和夜晚的公园还是小地图，没有一起放大。
- 小树林的音乐沿用公园的夜晚音乐，可以换。
