# 第 1 张新地图：公园外的小树林

配图：`docs/maps/forest-grove-layout.png`。已经做好，可以玩。

## 一句话

从夜晚公园向外延伸的一片小树林：一条蜿蜒的土路，三块空地，一个藏在灌木后面的“猫猫的小秘密”，尽头是出口。地图大小 2304×1280（72×40 格，每格 32 像素），画面会跟着小猫滚动，不会照到地图外面。

## 怎么进来

- **通关公园之前**：夜晚出门和以前一样，直接去公园，不会看到选择界面。
- **第一次通关公园（清空史莱姆、走进出口）之后**：夜晚出门会先弹出“今晚去哪里探险？”，可以选“公园”或“小树林”。已通关的地图会标 ✓。
- 想先不出门，点“先不出门”或按 Esc。
- 探险进行到一半存档、退出再继续，会回到你选的那张地图。

## 通关规则（和公园一样）

- 打败**外面的 8 只**史莱姆，出口才会开启；走进出口算成功撤离，并记录“已通关小树林”。**秘密小径里的守卫（共 9 只里的 1 只）不算通关目标**，打了照样掉东西、读档后也不会复活，不打也能通关，所以秘密是真的可选。
- 屏幕右上角显示“目标 x/8”。剩 3 只以内时，屏幕边缘会出现红色小箭头指向它们（只指向算目标的敌人，不指向守卫），全部打完后变成金色箭头指向出口。
- 途中 2 个安全点，碰到就激活，倒下后在最近的安全点复活（2 条命）。
- 没碰过安全点就倒下，会回到出发点。

## 猫猫的小秘密

- 入口空地北边有一条被灌木半挡住的窄小径，入口附近的地上有**很淡的爪印**当提示。
- 走到老树洞，触发“猫猫的小秘密！”，学会三段连击，屏幕顶部弹出提示条。再来一次只会提示“这里你来过了”。
- 不是通关必需。

## 怎么改这张图（给你和美术同学）

这张图是用**地砖地图（TileMapLayer）**做的，美术是占位的，可以直接替换，不需要改任何关卡代码：

1. **换地砖图**：用 Aseprite 画一张 352×32 的图（11 个 32×32 的格子排成一行），顺序是：草地 A、草地 B、土路、树 A、树 B、树 C、灌木、水、花丛、小石头、浅色土路（秘密小径）。覆盖 `assets/tilesets/forest_tiles.png` 就行。碰撞（树、灌木、水不能走）已经设在地砖上。
2. **直接在 Godot 里重新刷地图**：打开 `scenes/worlds/forest_grove.tscn`，选中 `Terrain` 节点，用地砖地图编辑器画。
3. **换道具图**：`assets/props/pawprint.png`（爪印）、`assets/props/tree_hollow.png`（老树洞）。
4. 敌人、安全点、出口、秘密点都是场景里的普通节点，在 Godot 里直接拖动位置即可。

## 重新生成（只有想从头来过时才需要）

关卡数据在 `tools/forest_grove_data.py`（唯一的数据来源）。改了数据之后：

```
python3 tools/make_forest_tiles.py      # 生成地砖图、占位美术、地砖网格，并检查设计
python3 tools/draw_map_layout.py        # 重画 docs/maps/forest-grove-layout.png
godot --headless --path . --script res://tools/build_forest_grove.gd   # 重新生成场景
```

`make_forest_tiles.py` 会自动检查：所有敌人、安全点、出口、秘密点都必须站在可走的地面上，并且从出发点能走到。**注意**：重新生成场景会覆盖你在 Godot 里手动改过的内容。

## 测试

`tests/forest_grove.gd`（66 项）包括：场景结构、9 只敌人、地砖数据里的可达性、**用真实物理碰撞让小猫沿土路一路走到出口、沿秘密小径走到老树洞**（走不通就失败）、树和池塘能挡住小猫、走到树洞真的学会招式且只学一次、爪印足够淡、鏡头跟随并且不会照到地图外面、只杀守卫不会让出口开启、只杀外面 8 只就会开启并记录通关。`tests/enemy_compass.gd`（23 项）覆盖方向箭头的几何计算和指向规则。`tests/playtest_launcher.gd` 覆盖一键试玩入口。`tests/map_system.gd` 覆盖选图界面、通关记录、存档兼容。

## 已知限制 / 后续

- 美术是占位的程序生成图，比较单调（树墙都是同样的方块），等你们换成手绘的。
- 史莱姆的追击是直线走，在树墙之间可能会被卡住，等做敌人家族时一起改进路线。
- 夜晚的战斗界面（左上角的大面板）还是旧样式，会挡住一大块视野，需要单独做一次像素风的紧凑改造。
- 小树林的音乐沿用公园的夜晚音乐，可以换。
