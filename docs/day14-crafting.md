# PixelCat · Day 14 — 双模式合成系统

## 设计（2026-11-08）

- **随身合成**：按 I 打开已有背包，点击“♡ 制作物品 ♡”进入合成界面。
- **工作台合成**：白天接近家里的小桌子，按 E 打开相同界面，并启用工作台限定配方。
- **反馈**：制作配方始终可见。随身模式的高级配方显示锁和“需要工作台”；材料不足或无背包空间则禁用制作。可按 Esc 或 I 关闭合成。
- **操作锁**：两个合成模式都使用现有 InventoryManager.ui_open，保留角色移动/战斗/交互冻结。
- **材料美术**：粉色捆装毛线（独立新物品 yarn）、木材 wood、石头 stone，来自已确认的像素设计；没有背景、光晕或阴影。原有 yarn_ball 保留独立物品 ID。
- **基础配方**：毛线 ×2 → 毛线球 ×1（随身）；木材 ×2 + 二级毛线球 ×1 → 毛线逗猫棒 ×1（工作台）。
- **消耗效果**：毛线逗猫棒可在背包或快捷栏使用，一次消耗 1 个、心情增加 20（上限 100）；满心情不能使用，避免浪费。毛线球只作为二级合成材料，不可绑定快捷栏。
- **史莱姆掉落**：每只击败后以 50%/30%/10%/10% 分别掉落 1/2/3/4 个材料，每个独立等概率为毛线、石头、木材；未拾取材料持久化、背包满时不会丢失。原小鱼干机制继续保留。
- **启动与世界切换**：本分支已整合启动菜单（新游戏、继续游戏、退出和存档恢复），默认场景为菜单，Day 14 从菜单开始可试玩。工作台改为独立像素立绘，逗猫棒改用新的像素图标。

## 架构

`resources/crafting/crafting_recipe.gd` 与两个 .tres 配方负责数据。Autoload `CraftingManager` 负责列表、可合成性、工作台限制、对 InventoryManager 事务的调用。独立 `CraftingUI` 用于两种来源，`CraftingWorkbench` 是白天场景的可交互 Area2D。

重要：`InventoryManager.craft_items` 先完整复制 24 格槽位，然后从副本扣材料、再尝试在副本中放入成品。成功后一次性替换槽位，发出相应信号并存档一次；失败不修改真实背包。预览 `preview_crafting` 完全不修改状态。允许材料与产物 item_id 相同。

## 需验收的情况

- 随身制作普通配方 / 随身不能制作高级配方 / 工作台能制作高级配方
- 材料不够 / 背包已满 / 消耗材料后恰好腾出空格 / 输出堆叠不足
- 完成后的物品进入背包，快捷栏通过 inventory_changed 更新；存档重载后数量正确
- 重复快速点击时不得生成超出材料的物品
- I / Esc 关闭面板；合成期间禁止移动、翻滚、攻击与再次 E 交互
- 启动菜单 PR #1 的修改已经整合进当前分支，本 PR 为统一验收入口；不得直接合并 main
