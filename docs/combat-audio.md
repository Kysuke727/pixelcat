# 战斗音效接入说明（给负责音乐的同学）

战斗里每个动作都留好了“音效槽”。**不需要改任何代码，也不需要在 Godot 里拖东西**：把音效文件放进 `assets/audio/sfx/combat/`，文件名对上就会自动播放。没有放文件的事件就是静音。

支持 wav / ogg / mp3（短音效推荐 wav 或 ogg）。每次播放音调会有一点点随机变化，连续命中时不会听起来一模一样。

## 文件名和触发时机

| 文件名 | 什么时候响 | 建议风格 |
| --- | --- | --- |
| `claw1` | 第一下爪击，挥出去的瞬间 | 轻快的“嗖” |
| `claw2` | 第二下爪击 | 和 claw1 同类，音调略不同 |
| `claw3` | 第三下重爪 | 更重、更长的“嗖” |
| `pounce` | 扑击 | 短促有力的扑出去 |
| `counter` | 反击爪（完美闪避之后） | 清脆、有一点魔法感 |
| `hit_light` | 普通命中 | 轻轻的“啪” |
| `hit_heavy` | 重击命中（三段连击、扑击） | 更厚、更有力的打击声 |
| `crit` | 绕背暴击 | 最爽的一个，响亮的“咔” |
| `dash` | 冲刺 | 一小下“嗖” |
| `dodge` | 闪避 | 轻快的翻身声 |
| `perfect_dodge` | 完美闪避 | 清亮的“叮”，会触发慢动作 |
| `perfect_guard` | 完美防御 | 金属感的“当” |
| `player_hurt` | 小猫受伤 | 短促、不要太吓人 |
| `slip` | 滑倒 | 滑稽的“呲溜” |
| `stick` | 被史莱姆黏住 | 黏糊糊的声音 |
| `learn_move` | 学会新招式 | 开心、有成就感，约 1 秒 |

敌人自己的攻击、受击、死亡声已经有了（`assets/audio/sfx/enemy_*.mp3`）。

## 小提示

- 命中和挥爪可能在 0.1 秒内连着响，请做得短（不超过 0.3 秒）。
- `hit_*` 和 `claw*` 会同时出现，注意音量别互相盖住。
- 想暂时全部关掉，可以把 `HitFeel.sfx_enabled` 设为 false（以后做设置界面时会用到）。
- 目前所有音效都走 Master 总线。以后如果要单独调战斗音量，需要新建 `SFX` 总线。
