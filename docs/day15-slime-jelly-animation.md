# PixelCat Day 15 — 史莱姆果冻跳（程序动画 V1）

**基础分支**：`feature/day14-crafting`，沿用 Day 14 的合成、菜单和夜晚掉落。当前版本额外增加了蓄力大跳的真实攻击位移。

## 演出设计

史莱姆仍然只有四方向 64×64 单帧贴图，动画通过 Sprite2D 的局部位置、缩放，以及位于角色后面的独立地面阴影表现：

- **待机**：1.2 秒微弱呼吸，身体尺寸变化不超过约 2.5%。
- **巡逻**：0.43 秒一个小跳，幅度为标准跳跃的 80%。
- **追击**：0.32 秒一个较快的果冻跳，幅度为 112%。
- **标准跳跃曲线**：0% 正常 → 14% 压扁蓄力 → 30% 伸长离地 → 53% 腾空顶点 → 72% 下落 → 83% 啪叽落地 → 93% 微弱反弹 → 100% 回到正常。
- **攻击前摇**：变宽压扁，沿用原有橙红色提示。
- **冲刺**：拉长、微微腾空，沿用冲刺颜色。
- **受击**：根据受击剩余时间快速压扁。
- **眩晕、毛线束缚**：变扁、不再正常跳动；束缚还会轻微扭动。
- **死亡**：先扁成一滩，之后用原有 0.28 秒缩小消失动画。
- **影子**：纯色、清晰像素边缘的扁椭圆，腾空时缩小并变浅，不用模糊或柔光。

参数都可以在 Slime Inspector 的 Jelly Animation 分类中调整：巡逻周期、追击周期、追击幅度、平滑强度。

## 技术原则

- `scripts/enemies/slime_jelly_motion.gd` 保存可单独测试的分段动画曲线。
- `scripts/enemies/slime_shadow.gd` 绘制并控制地面阴影。
- `scripts/enemies/slime.gd` 根据原有状态机决定动画目标值，再平滑驱动视觉节点。
- 仅改变 `Sprite2D.position/scale` 和 `JellyShadow.scale/modulate`；**不得改变 CharacterBody2D 位置、速度定义、碰撞体、攻击范围和判定**。
- 保留受击闪白、原有方向贴图和死亡缩小逻辑。
- 顺手修复 `_die()` 中原有的材料掉落空数组类型转换错误：在非探索状态死亡时，不再尝试把普通 Array 强转为 Array[Dictionary]。

### 实机调整建议

## Day 15 V2：真正的蓄力远跳（用户试玩反馈）

之前 V1 只有日常巡逻/追击果冻跳以及近距离冲刺，无法看出“有准备动作的远距离攻击”。V2 改为玩家进入警戒范围后，史莱姆停下蓄力，然后 **CharacterBody2D 真正向前长距离跳跃**：

1. **感知与触发**：警戒范围原有 250px；当小猫接近到 `attack_range = 135px` 且攻击冷却归零，立刻由 CHASE 进入 WINDUP。
2. **原地蓄力**：默认 `slime_windup_duration = 0.68s`，锁定小猫进入范围时的位置；史莱姆逐渐变宽、变扁、下沉，颜色逐渐更暖，末段轻微发抖；这段时间完全不前进。
3. **长距离跳扑**：`lunge_speed = 285px/s`、`lunge_duration = 0.45s`，无遮挡时理论最多位移 `128.25px`。身体视觉额外腾空最多 19px，地面阴影缩小，朝锁定方向移动，**跳到一半不自动追踪猫咪**，给玩家留出闪躲和弹反空间。
4. **落地与恢复**：恢复原有攻击冷却、RECOVER 后继续追击；旧移动跳与贴地阴影仍保留，不影响受击/束缚状态。
5. **系统相容**：沿用已有 LUNGE 命中、碰撞、盾、弹反、失衡和 `get_attack_eta_for`，不改攻击伤害、不加额外攻击判定。

这一轮将默认 AI 攻击参数改得更具威胁，因此属于实质战斗调参。旧有“束缚结束后必须向前移动”的断言改为“恢复移动 **或** 进入攻击蓄力”，符合新攻击范围的 AI 行为。

## V2.1：完美防御时机收紧

远距离蓄力跳上线后，原有 `perfect_guard_window = 0.5s` 的命中预测窗口过宽：史莱姆尚在蓄力中段，玩家按 Z 就能提前成功弹反。

- 统一将 `CombatV3Tuning.perfect_guard_window`、`cat_controller.gd` 的 Inspector 默认值调整为 **0.25s**。
- `_try_perfect_guard()` 仍在**按下 Z 的瞬间**查询最近的预计命中时间；按得更早只进入普通防御，不会持续自动转成完美防御。
- **保留**普通格挡、盾牌耐久、松开重新按键的规则，成功完美弹反后的 `perfect_guard_pause_duration = 1.0s` 也暂不改。
- `tests/combat_v3_phase_d.gd` 现检查提前约 0.34s 的防御不弹反、约 0.18s 的防御可弹反，确保时机更明确。顺便使测试中的玩家初始盾耐久固定为 100，避免从存档/数值成长继承的当前最大盾耐久影响旧断言。
- 如果 Windows 实机仍觉得过于宽松，可考虑降低到 0.20s；如果太难，可改为 0.30s。当前 0.25s 相当于约 15 帧（60 FPS），适合作为第一轮手感测试。
